**N-Type** is a modern, high-performance web platform designed to elevate your touch-typing skills through a structured starter curriculum, custom AI-powered educational lessons, competitive practice modes, and arcade mini-games.
---
## 🌟 Key Features
### 🎓 1. Starter Touch-Typing Curriculum
- **Home Row Mastery**: Step-by-step muscle memory builder starting from home keys (`F` & `J`) and systematically branching outward.
- **Progress Persistence**: Your lesson completions and earned checkmarks are saved automatically to your browser's `localStorage`.
### 🧠 2. AI-Powered Dynamic Topic Generator
- Learn while you type! Enter any topic you want to learn about (e.g. *Space Exploration*, *Quantum Computing*, *Ancient Rome*), and the engine will generate an educational passage to read and type.
- **Built-in Offline Engine**: Works out-of-the-box with a rich built-in topic database — no setup required!
- **Gemini 2.0 Flash Integration**: Optional support for your own Google Gemini API key to generate limitless custom lessons in real time.
### ⚡ 3. Timed & Word Practice Tests
- Test your limits with customizable tests:
  - **Time Modes**: 15s, 30s, 60s
  - **Word Counts**: 25, 50, 100 words
  - **Categories**: Famous Quotes, Programming Code snippets, and Common Words.
- Real-time tracking of **WPM** (Words Per Minute), **Accuracy**, and **Raw WPM**.
### 🎮 4. Arcade Mini-Games (Fullscreen Immersion)
- **Key Laser**: Defend your base from descending letters by typing them before they hit the ground.
- **Word Sprint**: Race against the clock by typing entire words to keep your combo alive.
- Features automatic **fullscreen mode** upon launch to eliminate distractions.
### ⌨️ 5. Smart Interactive Keyboard
- An on-screen virtual keyboard that slides up automatically when an assessment starts and hides when inactive.
- Displays key bumps, active finger placement guidance, and live reactive keypress highlights.
### 📊 6. Analytics & Performance Tracking
- Visual speed history charts and performance metrics breakdown.
